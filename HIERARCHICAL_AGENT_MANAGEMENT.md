```
Каждый бригадир отчитывается:

- ETA: когда блок будет готов?
```

**18:00** - Координатор пишет итоговый отчет
```
Сводка за день:
- Бригадир #1: Frontend progress X%
- Бригадир #2: DevOps progress Y%
- Бригадир #3: Backend progress Z%
- Всего: общий прогресс? На графике?
- Блокировки: что мешает?
- План на завтра: что дальше?
```
